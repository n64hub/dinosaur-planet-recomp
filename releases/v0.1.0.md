The first release of Dinosaur Planet: AI Slop Recomp for Windows and Linux: a native PC port of the December 2000 prototype of Rare's *Dinosaur Planet* for the N64, made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of that prototype (a big-endian `.z64` of 64 MiB, MD5 `49f7bb346ade39d1915c22e090ffd748`). No other build of the game is supported.

> **This is AI slop.** AI agents wrote every line of it: the code, the fixes, the docs. You almost certainly want [Dinosaur Planet: Recompiled](https://github.com/DinosaurPlanetRecomp/dino-recomp) instead, which people made carefully, by hand. Its developers ask that AI not be used on their work, so this one is for anyone who wants to work on or mod Dinosaur Planet with AI. Please don't throw shade at them for that wish: everyone is allowed to wish things.

**Windows:** unzip `DinosaurPlanet-v0.1.0-windows-x64.zip` and run `DinosaurPlanet.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `DinosaurPlanet-v0.1.0-linux-x64.tar.gz` and run `DinosaurPlanet` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What you get:** the prototype from a new game to Drakor's end and the credits. As it is on the ROM, the prototype crashes, softlocks or has no way on in many places, so it can't be played to its end; this version fixes each of those it found, and finishes the story's unfinished parts from what the game's own code and data already hold: all eight Krazoa shrines and each spirit's release, the Krazoa tablets, Walled City's gate and its King, the BOSS TRex's SpellStone, the Kamerian Dragon, CloudRunner Fortress's treasure caves and baby CloudRunners, Krazoa Palace's four wings, and the game's own credits after Drakor. Restored content was inferred from the ROM as much as possible, and the rest reasoned out as the simplest and most likely intended path, so it may differ from other restorations of the game. Each restoration is behind its own setting, Restored by default; Original plays the ROM as it is there. Crash fixes and plain bug fixes are always on.

**Enhancements**, each an option with a value that plays as the console does:

- High resolution at the window's size, with anti-aliasing
- Smooth motion at the display's refresh rate, blended between the game's 30 frames a second
- Widescreen: the world reaches the window's edges, and the HUD's panels move out to them
- A free camera on the right stick and the mouse
- Keyboard and gamepad controls, rebindable
- Mods: N64Recomp mods (`.nrm`) and RT64 texture packs (`.rtz`) from the `mods` folder, with an example mod to start from in the repo (README, Mods). AI contributions are welcome here, hand-written ones too.

**Not checked yet:** AI agents have played every stretch of the story, each from its own starting point, but never in one sitting, and no human has played it, so a stretch may still stop you, and expect graphical glitches: textures tiled wrong, letterbox bars where none belong, sprites and objects that flicker. Report them on the [issues page](https://github.com/n64hub/dinosaur-planet-recomp/issues), saying where you were and what you did. The Linux build has been booted on Mesa's software Vulkan only.

The same game plays in a browser at [n64hub.com/dinosaur-planet](https://n64hub.com/dinosaur-planet/), without mods. The [README](https://github.com/n64hub/dinosaur-planet-recomp#readme) has how to build it yourself.
