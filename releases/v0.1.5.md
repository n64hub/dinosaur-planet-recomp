An update of the renderer and runtime every recomp of this project shares. Like v0.1.4 it contains no game data: you need your own ROM of that prototype (a big-endian `.z64` of 64 MiB, MD5 `49f7bb346ade39d1915c22e090ffd748`).

> **This is AI slop.** AI agents wrote every line of it: the code, the fixes, the docs. You almost certainly want [Dinosaur Planet: Recompiled](https://github.com/DinosaurPlanetRecomp/dino-recomp) instead, which people made carefully, by hand. Its developers ask that AI not be used on their work, so this one is for anyone who wants to work on or mod Dinosaur Planet with AI. Please don't throw shade at them for that wish: everyone is allowed to wish things.

**Windows:** unzip `DinosaurPlanet-v0.1.5-windows-x64.zip` and run `DinosaurPlanet.exe` from that folder. **Linux (x86-64):** extract `DinosaurPlanet-v0.1.5-linux-x64.tar.gz` and run `DinosaurPlanet` in that folder. What each needs, and everything else about the game, is in [v0.1.0's notes](https://github.com/n64hub/dinosaur-planet-recomp/releases/tag/v0.1.0).
